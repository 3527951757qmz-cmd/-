极值点偏移：从概念到题型变式（可视化）

核心思想：如果原函数 f(x) 的极值点已知，那么经过平移、伸缩、翻折后，新的极值点可以“按规则搬家”。

本页按 引入 → 基础题型 → 多变式 组织，适合高二/高三函数压轴前的专题复习。

1. 引入（直观看偏移）

取基准函数：f(x) = x³ - 3x，其极大点为 (-1, 2)，极小点为 (1, -2)。

构造新函数：g(x) = f(x - p) + q。拖动参数观察“极值点整体平移”。

2. 基础题型（必会模板）

模板 A：已知原函数极值点，求平移后极值点

若 f(x) 在 x = x₀ 处有极值，且 y₀ = f(x₀)，则 g(x)=f(x-p)+q 的对应极值点为 (x₀+p, y₀+q)。
  • 先锁定“原极值点坐标”。
  • 看表达式中的 x-p：横坐标整体 +p。
  • 看外面的 +q：纵坐标整体 +q。
  • 最后代入并核对“极大/极小”类型是否改变（平移不会改变类型）。

模板 B：已知新极值点，反推参数

比较坐标：x新 = x旧 + p，y新 = y旧 + q。列二元一次方程组即可求 p, q。
3. 多变式进阶（常见压轴变形）

变式 1：含伸缩与翻折

g(x)=A·f(B(x-p))+q
  • x方向：先由 B 造成横向伸缩，再由 p 平移；当 B<0 时关于竖直线 x=p 发生左右翻折。
  • y方向：由 A 造成纵向伸缩；A<0 时极大/极小互换，再整体上移 q。

变式 2：参数范围题

常见问法：两极值点都落在某区间内、极值和差满足不等式、极值点到某直线距离最小等。核心仍是先把新极值点坐标写成参数表达式，再做不等式约束。

变式 3：与导数联动

若题目不给原极值点，可先用 f'(x)=0 求出原极值点，再套“偏移映射”一步到位。导数负责“找点”，偏移负责“搬点”。
